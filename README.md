# Superstore Sales Dashboard

## Project Overview
Developed an interactive Power BI dashboard to analyze sales, profit, discounts, customer segments, and regional performance using the Superstore dataset.

## Objectives
- Track sales performance
- Identify profitable regions and categories
- Analyze customer segments
- Generate business insights

## Tools Used
- Power BI
- Excel
- Power Query
- DAX

## Key Insights
- Technology category achieved highest sales
- West region generated maximum profit
- Discounts reduced profitability in some categories

## Features
- KPI Cards
- Interactive Filters
- Sales Trend Analysis
- Category & Regional Analysis
